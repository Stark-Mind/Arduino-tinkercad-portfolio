# ⚡ Project: LED Blinking Wave (Optical Pulse Array)

---

## 🦾 Overview
Forget static lighting. This module orchestrates a synchronized **blinking wave** across a multi-stage LED array. Controlled via micro-controller timing loops, it sequences current across five distinct channels to create a cascading optical effect. 

Think of it as a low-voltage diagnostic display for your workbench—proof that sequential logic can look sharp.

## 🛠️ The Hardware Manifest
* **Processing Unit:** Arduino Uno R3 
* **Optical Output:** 5x Red LEDs *(Not quite repulsor tech, but it gets the job done)*
* **Current Regulators:** 5x 560Ω Resistors *(To keep things from going up in smoke)*
* **Prototyping Matrix:** Standard breadboard & jumper wiring
